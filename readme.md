# Typing Speed Test #

A simple JFrame program to test your typing speed.

### Why
For fun, and maybe to keep my brain from getting rusty.

### How
It's Java. I don't think non-Java Programmer will see this, and Java programmers know how to run it.

Just In Case: 1
```text
launch you ide and run the main class 
```
Just In Case: 2
```bash
cd thisdir
mvn clean package
java -jar ./target/typingspeed-1.0-SNAPSHOT.jar
```

## Requirements

- maven
- JDK 17+ (never mind. you can change it)
- A desktop environment, since JFrame needs a GUI
